# Kissrecord

纯静态录音 + 声波可视化小工具（HTML + 原生 JS + CSS，零依赖、零构建）。

## 怎么打开

直接双击 `kissrecord.html` 用浏览器打开（不用装任何东西）。

> 浏览器会询问麦克风权限，允许后才能录音。`系统.html` 是配套的整理说明页面。

## 核心功能

- 浏览器麦克风录音 + 实时波形 / 频谱可视化
- 录音保存 / 回放 / 导出
- 配套 `系统.html`：系统级说明文档

## 技术栈

纯静态前端（HTML + JS + CSS），`MediaRecorder` + `Web Audio API`，无任何依赖。

## 文件结构

| 文件 | 用途 |
|------|------|
| `kissrecord.html` | 主入口（双击这个） |
| `kissrecord.js` | 录音与可视化逻辑 |
| `kissrecord.css` | 样式 |
| `系统.html` | 系统说明页 |
