# Bubble Pop Keyboard

打字练习 + 弹跳按键 + 音效反馈的小游戏（Vite + React + TypeScript + MUI + Tailwind）。

## 怎么打开

```bash
npm install
npm run dev
```

浏览器开 http://localhost:5173

## 核心功能

- 屏幕键盘按键，按下时弹跳 + 音效反馈
- 打字练习 / 节奏游戏模式
- MUI v9 + Tailwind v4 双栈样式

## 技术栈

| 类别 | 选型 |
|------|------|
| 构建 | Vite 8 + TypeScript 6 |
| UI | React 19 + @mui/material 9 + @emotion |
| 样式 | @tailwindcss/vite 4 |
