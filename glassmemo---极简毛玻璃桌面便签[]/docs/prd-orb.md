# PRD：悬浮球模式（Orb Mode）— 缩小到悬浮球

> **增量 PRD**：本文件仅描述"完整便签 ↔ 悬浮球"的形态切换功能，不重写现有 PRD / 桌面插件设计。
> 沿用既有技术栈与桌面层嵌入方案。

---

| 字段 | 值 |

### 原始需求复述

在已有桌面便签（glassmemo）的右上角**新增一个"缩小"按钮**，点一下：
- 主便签窗口从"完整便签"收缩成一个**悬浮球**（floating orb / mini button）
- 悬浮球停留在桌面，**可拖动**
- 点悬浮球 → 重新展开回完整便签

---

## 2. 产品定义

### 2.1 Product Goals（3 个正交目标）

1. **形态切换无缝**：从完整便签收缩到悬浮球、从悬浮球展开回便签，两次切换都对用户透明、不阻塞、不重启进程。
2. **悬浮球作为"桌面常驻最小化形态"**：可拖动、视觉风格延续暗色霓虹毛玻璃、内容只剩一个圆 + 图标。
3. **不破坏既有桌面插件语义**：悬浮球与完整便签共用同一个 `BrowserWindow`、同一套桌面层（WorkerW 嵌入）、同一套浮窗置顶状态（pinned）。

### 2.2 User Stories

- As a 用户，我想要便签收起来只占桌面一个小角落 **so that** 不会遮挡视线、看代码/做设计时不被挡住。
- As a 用户，我希望点悬浮球能随时把便签召回来 **so that** 写东西时不需要再去托盘打开。
- As a 用户，我希望悬浮球能拖动 **so that** 可以挪到不碍事的位置。
- As a 用户，我希望悬浮球位置能被记住 **so that** 重启后还是上次放的位置，不用每次都拖。

### 2.3 边界（不做什么）

- **不做**悬浮球的右键菜单（已有托盘菜单够用，最小入口）
- **不做**悬浮球的多实例（永远是同一个主便签的最小化形态）
- **不做**悬浮球的自定义图标（沿用玻璃拟态圆 + 内置便签/记事本 SVG 图标）
- **不重写**现有 PRD / 桌面嵌入方案 / 窗口置顶设计

## 3. 技术规范

### 3.1 Requirements Pool

#### P0（必须实现）

- 右上角新增"缩小"按钮：图标明显（如 Lucide `Minus` 或 `ChevronDown`），hover 高亮，遵循既有深色霓虹毛玻璃视觉风格
- 收缩动画：从完整便签的当前 `bounds` 平滑过渡到悬浮球 `bounds`（约 **60×60 px 圆形**，偏差 ±8px），使用 Motion 12 实现或 CSS transition
- 内部状态：`view: 'note' | 'orb'`，React state，通过新增 IPC `view:change` 通知主进程调整 `win.setBounds(...)`
- 悬浮球可拖动
  - 鼠标按下/拖动/抬起在渲染层完成
  - 位置限制在屏幕内（多屏拼接时按当前 display 工作区裁剪）
  - 释放时若距屏幕左/右边缘 ≤ 30px，则**贴边**吸附
- 展开回完整便签
  - 点悬浮球 → 展开
  - 恢复到缩小前的 bounds（先持久化到 `userData/note-bounds.json`，展开时读回）
- **桌面层语义保持**：悬浮球模式下仍调用 `applyLayer`（`SetParent → Progman → WorkerW`），被其它程序盖住、Win+D 仍可见
- **pinned 状态保持**：若缩小前是 `pinned=true`（浮窗置顶），缩小后悬浮球保持置顶；展开回完整便签也保持同一状态

#### P1（应该实现）

- 悬浮球 UI：完整便签内容（便签列表 / 编辑器 / 日期）全部隐藏，仅渲染 **玻璃圆 + 居中发光图标**（便签 / 记事本 SVG）
- 悬浮球 hover/active 时**微放大**（scale 1.0 → 1.05）+ 阴影增强，230ms 缓动
- **双击**悬浮球 = 展开（与单击展开等价）
- 托盘菜单新增「折叠为悬浮球」快捷入口（调用与按钮等价的 IPC）
- 缩小动作时**自动保存当前便签内容**（与现有 `onChange` 持久化一致，不另写代码路径）

#### P2（可选实现）

- 悬浮球显示小红点提示"今日有便签更新"（依赖现有便签元数据，本 PRD 不定义规则）
- 悬浮球收缩 / 展开动画时长可配置（默认 **250ms**，缓动 `cubic-bezier(0.4, 0, 0.2, 1)`）
- 悬浮球右键 = 弹出托盘菜单的精简版（仅"显示完整便签 / 退出"）

### 3.2 UI Design Draft

#### 完整便签（`view: 'note'`）

```
┌────────────────────────────────────────────────┐
│                                                │
│  [便签内容...]                  ─  ▾  ✕        │   ← 右上角三个图标（左 → 右）
│                                                │      「窗口置顶切换」「缩小」「关闭到托盘」
│  YYYY-MM-DD                                    │
│                                                │
└────────────────────────────────────────────────┘
```

图标顺序约束：本 PRD **新增的「缩小」置于「窗口置顶切换」与「关闭到托盘」之间**，不调整既有按钮位置。

#### 悬浮球（`view: 'orb'`）

```
        ╭─────────╮
        │   📝   │      ← 直径 56–64 px 圆形
        │ glow   │         深色霓虹毛玻璃背景（沿用 glassdemo 视觉）
        ╰─────────╯         中心一个发光的便签 / 记事本 SVG 图标
                            hover: 圆微微放大 + 图标变亮
                            点击 / 双击: 展开回完整便签
```

## 4. 验收标准（共 18 条，可测试）

### 4.1 缩小行为（4 条）

- **AC-1**：右上角"缩小"按钮可见，鼠标移上去有 hover 高亮，命中区域 ≥ 24×24 px。
- **AC-2**：点击"缩小"后，便签窗口 bounds 在 **200–300ms** 内过渡到 ≤ 80×80 px（实际渲染约 60×60 px 圆形）。
- **AC-3**：悬浮球出现位置在完整便签当前屏幕位置的相邻区域（动画过渡，非瞬移；偏差 ≤ 完整便签宽度的 50%）。
- **AC-4**：悬浮球模式下，便签列表 / 编辑器 / 日期 / 顶部时间条等内容在视觉上不可见（DOM 可存在但被覆盖或 `display:none`）。

### 4.2 展开行为（4 条）

- **AC-5**：单击悬浮球，便签窗口在 **200–300ms** 内展开回完整便签。
- **AC-6**：展开后的位置与尺寸 = 缩小前的位置与尺寸（自 `userData/note-bounds.json` 读回，精度 1px）。
- **AC-7**：展开后便签内容完整可编辑，光标焦点、滚动位置、临时输入不丢失。
- **AC-8**：双击悬浮球与单击悬浮球行为等价（同样展开）。

### 4.3 悬浮球交互（4 条）

- **AC-9**：悬浮球可被鼠标按下并拖动到屏幕任意位置（多屏环境按当前 display 工作区）。
- **AC-10**：拖动超出屏幕范围时，悬浮球位置被限制在屏幕内，不出现标题栏外不可见的状态。
- **AC-11**：悬浮球拖到屏幕**左或右边缘 ≤ 30px** 释放时，自动贴到该边缘（吸附后中心距边缘 0–16 px）。
- **AC-12**：悬浮球位置持久化到 `userData/orb-bounds.json`；关闭再打开 / 重启后位置仍保留。

### 4.4 不破坏既有行为（3 条）

- **AC-13**：悬浮球模式仍调用 `applyLayer` 嵌入 WorkerW；被其它程序窗口盖住时不可见，Win+D 后仍可见（桌面级而非应用级 z-order）。
- **AC-14**：先切换到"浮窗置顶"（`pinned=true`）再缩小，悬浮球保持置顶；展开回完整便签后置顶状态不变。
- **AC-15**：缩小后点 X 关闭按钮：进程不退出、窗口消失、托盘图标仍在（与既有"关闭=隐藏到托盘"一致）。

### 4.5 视觉与稳定性（3 条）

- **AC-16**：悬浮球视觉延续暗色霓虹毛玻璃风格（玻璃质感圆 + 发光图标），与完整便签主色调/光晕一致，无明显色差或锯齿。
- **AC-17**：收缩 / 展开动画时长 200–300ms，整过程不卡顿（主线程 FPS ≥ 50，动画期间无掉帧 > 100ms）。
- **AC-18**：连续快速点击缩小 / 展开（≥ 5 次 / 2s 内）不崩溃、不残留中间状态（最终态唯一：`'note'` 或 `'orb'`，与最后一次点击一致）。

## 5. 附录：约束与基线（来自既有实现，本 PRD 不重写）

> 仅作为本 PRD 编写时的"已知约束"存档，不属于新增需求。

- **桌面嵌入**：`koffi` 3.2.1 调 Win32 `SetParent` → `Progman → WorkerW`，已在 `main.cjs` 通过 `applyLayer` 接入
- **IPC 通道**：`pin:toggle` / `pin:get` / `pin:change` + `app:hide` / `app:quit`（contextBridge 暴露为 `window.glassmemo`）；本 PRD 新增 `view:change`
- **样式基线**：glassdemo 暗色霓虹毛玻璃风格，禁止破坏
- **打包配置**：`asar: false`、`./desktop-layer.cjs` 显式 `.cjs`
- **单实例**：单实例锁；关闭按钮 = 隐藏到托盘，不退出进程
