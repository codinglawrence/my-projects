# Principle Retro · 原则复盘

> 单文件 `index.html` 版的《原则》个人复盘 MVP，零依赖、零安装、双击即开。
> 完整设计与提示词见 `BUILD-PROMPT.md`。

## 怎么打开

直接双击 `index.html` 用浏览器打开（数据存浏览器 `localStorage`，不上传任何服务器）。

## 核心功能（五块，克制不堆）

1. **五步流程录入**：主题 / 目标 / 问题 / 根因 / 方案 / 执行，按"目标→问题→根因→方案→执行"分块写
2. **偏差开关 + 痛苦卡**：勾偏差必须填反思才能提交
3. **原则库**：带偏差的复盘提交时，反思自动沉淀为原则；可手动添加；失效原则只标灰、不物理删除
4. **演化树**：原则按时间竖向时间线，灰色表示失效
5. **数据安全**：一键导出 / 导入 JSON；清空前强制二次确认

## 设计原则（与 BUILD-PROMPT.md 一致）

- 高频 > 酷：不做 AI 自动提炼 / 多人 / 仪表盘
- 偏差即燃料：偏差必反思、必沉淀
- 原则可演化：可失效不删除
- 精力约束：打开即用、写完即走
