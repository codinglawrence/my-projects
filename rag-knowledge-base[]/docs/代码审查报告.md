## 四、合并优先级修复清单（给 Engineer）

**P0（立即，安全阻断项）**
1. 轮换 `backend/.env` 的 DEEPSEEK / DASHSCOPE Key（C1），并核查是否已被盗用。
2. `JWT_SECRET_KEY` 改为 `secrets.token_hex(32)` 高熵值；`config.py` 生产环境拒绝默认值。
3. `ADMIN_PASSWORD` 改强口令（≥12 位）；首次启动要求改密。
4. nginx 启用 TLS，全链路 HTTPS（H3）。

**P1（发布前必修，功能可用性）**
5. `chat.py:68` SSE `except` 扩为 `except Exception` 兜底 error 事件；前端 `useSSE`/`chat.ts` 对 `reader.read()` 抛错 catch 并 reject（高）。
6. `rag_service.get_history_for_prompt` 排除当前刚写入的 user 消息，消除 prompt 重复（中，已验证）。
7. 文档列表改用 `DocumentResponse`（不含 `content`），`content` 仅 detail 返回（中）。
8. 提交 `backend/.env.example` 模板（H4）；`change_password` 加限流（M1）；CORS methods/headers 收敛（L4）。

**P2（技术债，发布后迭代）**
9. 同步 DB vs 文档"aiosqlite 异步"二选一统一（中/M2）；分离 `start.bat` 开发/生产模式（M3）。
10. Chroma `add` 异常上抛/回滚，勿静默 `print`（低）；复用单例 `PersistentClient`（低）。
11. 公共 API 补 docstring、魔法数字上提 `config.py`、注释率提到 ≥15%（注释 9 分→目标）。
12. `config.py` 类体内 `int()` 改到下方强转循环统一兜底（低）。
