# RAG 知识库问答系统 · 使用说明

> 适用版本：本地部署版（FastAPI + ChromaDB + DeepSeek + 阿里 DashScope 向量化 + React/Antd）
> 访问入口：**前端 `http://localhost:3000`** ｜ **API 文档 `http://localhost:8000/docs`**

---

## 1. 这东西是干嘛的

一个**基于私有知识库的问答系统**。先把你的产品文档/资料传进去，系统会切片、向量化、建索引；之后用户用自然语言提问，系统从知识库里检索相关段落，让大模型（DeepSeek）生成带**引用出处**的回答，而不是瞎编。

核心价值：**回答可控、可追溯**（每句话都标了来自哪份文档的哪段），适合做产品客服、内部知识助手、FAQ 机器人。

---

## 2. 两种角色

| 角色 | 怎么来 | 能干什么 |
|------|--------|----------|
| **管理员** | 系统内置账号 `admin`，密码在 `backend/.env` 的 `ADMIN_PASSWORD`（首次启动由 `init_admin.py` 自动创建） | 上传/管理知识库、重建索引、看数据看板 |
| **普通用户** | 在登录页点「注册」自己建账号（角色固定为 `user`） | 只能发起对话、提问、看回答和引用 |

> 普通用户**看不到**「知识库管理」和「数据看板」入口，那是管理员的地盘。

---

## 3. 管理员：先把知识库喂饱

### 3.1 登录管理员
1. 打开 `http://localhost:3000` → 登录页输入 `admin` / 你的 `ADMIN_PASSWORD`。
2. 登录后左侧菜单会出现「知识库管理」和「数据看板」。

### 3.2 上传文档
支持格式与限制：

| 项目 | 说明 |
|------|------|
| 支持格式 | `.txt`、`.md`、`.json` |
| 单文件大小 | ≤ 10 MB |
| 上传方式 | 页面上传 / 直接粘贴文本 |

两种录入方式：
- **文件上传**：在「知识库管理」页点上传，可选填标题（不填则取文件名）。系统自动切片 + 向量化 + 入库。
- **文本录入**：不想传文件，直接在页面里贴一段文字 + 标题，点「录入」即可成为一条知识。

### 3.3 维护知识
- **查看**：列表里能看到每份文档、点击可展开查看切成的「块（chunk）」。
- **删除**：某份文档过时了，删掉即可（同时移除对应索引）。
- **重建索引**：当你批量改了底层数据、或怀疑索引不一致时，点「重建索引」全量重跑（会遍历所有文档重新切片向量化）。

> ⚠️ 只有**管理员**能操作知识库。普通用户提问时检索的就是这里建好的索引。

---

## 4. 所有人：开始问答

### 4.1 注册 / 登录
- 没有账号：登录页点「注册」，填用户名 + 密码，立刻拿到 token 自动登录。
- 已有账号：直接登录。

### 4.2 发起一次对话
1. 进入「对话」页 → 点「新建会话」（不填标题默认叫「新会话」，发第一条消息后会**自动用问题内容命名**）。
2. 在输入框提问，例如：*“你们的产品支持导出 PDF 吗？”*
3. 回答**流式**逐字蹦出来（SSE），末尾或消息下方会附上**引用来源**（来自哪份文档的哪段），点引用可溯源。
4. 想换话题？再建一个会话，历史会话在左侧列表里都能翻回去。

### 4.3 提问小技巧
- **问得具体**，命中率更高。比如问“退款流程要几天”比“怎么退款”更容易检索到精确段落。
- 页面会按当前知识库给**建议问题**（最多 5 条），不知道问啥可点来试。
- 如果回答明显跑偏或说“找不到”，大概率是知识库里**没传对应资料**——回头让管理员补文档、必要时重建索引。

### 4.4 会话管理
- 列表查看历史会话与消息。
- 不想要了，「删除会话」即可，只删聊天记录，不动知识库。

---

## 5. 管理员：看板与运维

「数据看板」页（`/api/dashboard/stats`）汇总系统运行概况，包括文档总量、用户数、问答量等统计，用来判断知识库够不够全、系统用得勤不勤。

## 6. 给开发者：核心接口速查

所有接口前缀 `/api`，除注册/登录外均需 `Authorization: Bearer <token>`。

| 功能 | 方法 | 路径 |
|------|------|------|
| 注册 | POST | `/api/auth/register` |
| 登录 | POST | `/api/auth/login`（限 5 次/分钟） |
| 改密码 | PUT | `/api/auth/password` |
| 文档列表 | GET | `/api/knowledge/documents` |
| 文档详情+分块 | GET | `/api/knowledge/documents/{id}` |
| 上传文件 | POST | `/api/knowledge/documents`（form: file, title） |
| 文本录入 | POST | `/api/knowledge/documents/text` |
| 删文档 | DELETE | `/api/knowledge/documents/{id}` |
| 重建索引 | POST | `/api/knowledge/rebuild` |
| 会话列表 | GET | `/api/sessions` |
| 建会话 | POST | `/api/sessions` |
| 删会话 | DELETE | `/api/sessions/{id}` |
| 历史消息 | GET | `/api/sessions/{id}/messages` |
| 发消息(流式) | POST | `/api/sessions/{id}/send` |
| 建议问题 | GET | `/api/sessions/{id}/suggestions` |
| 看板统计 | GET | `/api/dashboard/stats` |

> 知识库类接口与看板均带 `require_admin` 守卫，普通用户调用会返回 403。
> 发消息返回 `text/event-stream`，事件类型：`chunk`（正文片段）、`done`（含 `citations`）、`error`。

## 7. 常见问题

**Q：传了 docx / pdf / xlsx 报错？**
A：当前版本只吃 `.txt / .md / .json`。Word/PDF 先转成纯文本或 Markdown 再传。

**Q：问答说“知识库里没有相关内容”？**
A：知识库没覆盖这个话题。让管理员上传对应资料，必要时点「重建索引」。

**Q：管理员密码忘了？**
A：改 `backend/.env` 的 `ADMIN_PASSWORD`，重启后端服务（`init_admin.py` 会用新密码重建 admin 账号）即可。

**Q：普通用户能管知识库吗？**
A：不能。知识库管理是管理员专属，避免随意改动检索源。

**Q：回答太慢？**
A：回答走 DeepSeek 流式生成 + 检索两步走。首次冷启动检索建库会稍慢，后续命中通常秒回。
