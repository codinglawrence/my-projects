# 原则 · 五步决策复盘系统

基于瑞·达利欧《原则》五步循环决策法（目标 → 问题 → 诊断 → 设计 → 执行）的个人/团队复盘工具，内置达利欧式 AI 导师与长期行为模式分析。

## 一键启动

```bash
cd "原则-·-五步决策复盘系统" && npm install && npm run dev
```

浏览器打开 http://localhost:3000

## 技术栈

- 前端：Vite + React 19 + TypeScript + Tailwind v4
- 服务端：Express + `@google/genai`（Vite 中间件开发模式，单进程同时托管前端与 API）

## 核心功能

- **五步复盘向导**：逐步引导填写，每步配达利欧式引导文案与「达利欧 AI 深度质询」按钮（无 API Key 时自动切换内置启发式导师）
- **个人原则库**：复盘第四步可一键提炼原则沉淀入库；支持标记失效归档（保留认知轨迹）
- **AI 行为模式分析**：跨全部复盘识别盲点 / 优势 / 高频陷阱，输出五步各环节成熟度与未来决策防御清单
- **未来决策事前尸检（Pre-Mortem）沙盘**：基于历史教训与原则库推演失败情景与防范机制
- **本地持久化**：数据存于 `data/principles_store.json`，首次运行自动写入种子案例

## AI 能力（可选）

服务端集成 Gemini。在 `.env.local` 写入：

```
GEMINI_API_KEY=你的key
```

即可开启实时大模型交互；**不填则全部走内置启发式引擎，所有功能正常可用**。

## 说明

- 数据存本地 JSON 文件；多端/多人同步需将服务部署到可访问的服务器（当前为单实例本地存储）
- 首次运行会自动生成 `data/` 目录与种子数据，不会覆盖你已有的数据文件
- 导出/备份请直接复制 `data/principles_store.json`
